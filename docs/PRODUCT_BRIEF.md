# Product brief — CRM + Copiloto Comercial

## Resultado buscado

Que ninguna conversación comercial dependa de la memoria de Felipe y que cada interacción produzca un siguiente paso, un aprendizaje o una decisión.

## Usuarios iniciales

- Codex: dueño del sistema operativo, CRM, tareas, pipeline y métricas.
- Claude: entrenador comercial; analiza conversaciones y mejora argumentarios sin editar el CRM.

## Flujo

1. Entra o se inicia una conversación.
2. Felipe conversa personalmente.
3. Se registra o importa la interacción.
4. El sistema identifica cliente, necesidad, producto, objeción y próxima acción.
5. Felipe confirma o corrige el análisis.
6. Se crea una tarea con fecha y responsable.
7. El panel muestra vencimientos y prioridades.
8. Las revisiones semanal/mensual/trimestral se calculan sobre datos reales.

## Relación con el Plan de Ventas

| Plan comercial | Registro del CRM |
|---|---|
| Contactos nuevos | Interacciones iniciales |
| Contactos efectivos | Conversaciones con necesidad o decisor identificado |
| Reuniones/relevamientos | Actividades agendadas y completadas |
| Propuestas | Oportunidades en etapa Propuesta |
| Clientes nuevos | Oportunidades Ganadas |
| Recompra | Nueva oportunidad vinculada al mismo cliente |
| Cross-selling | Oportunidad en otra familia/unidad |

## Cadencias

### Diario

- Bandeja de conversaciones pendientes.
- Seguimientos vencidos y de hoy.
- Cinco cuentas prioritarias.
- Registro inmediato posterior a cada interacción.

### Semanal

- 15 contactos nuevos.
- 8–10 contactos efectivos.
- 3–4 reuniones/relevamientos.
- 2–3 propuestas.
- Revisión de objeciones y una práctica de ventas.

### Mensual

- Clientes nuevos, conversión, ticket, recompra y cross-selling.
- Desempeño por canal, familia y responsable.

### Trimestral

- 10–15 clientes nuevos.
- Incremento outbound.
- Recompra y cross-selling.
- Decisiones de escala y automatización.

## Entidades mínimas

- Cuenta/empresa.
- Persona/contacto.
- Canal.
- Conversación.
- Interacción/mensaje o resumen.
- Oportunidad.
- Tarea.
- Producto/familia.
- Objeción.
- Evaluación comercial.
- Plantilla/respuesta rápida.

## Estados iniciales del pipeline

Nuevo → Contactado → Conversación → Calificado → Propuesta → Negociación → Ganado/Perdido/Pausado.

## Evaluación de conversación

El copiloto observa si el vendedor:

- identificó persona y rol;
- entendió necesidad, aplicación, volumen y urgencia;
- detectó proveedor actual y decisor;
- evitó promesas no confirmadas;
- definió próximo paso y fecha;
- mantuvo un tono adecuado;
- abrió una oportunidad futura de recompra o cross-selling.

## Privacidad

- Acceso restringido por usuario.
- Minimización de datos.
- Sin credenciales ni información financiera sensible.
- Registro de origen de cada conversación.
- La integración automática futura utilizará el canal oficial de WhatsApp Business Platform.
